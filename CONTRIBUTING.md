# Contributing

Create a focused branch from current `main`, link work to SPRINTS.md or BACKLOG.md, and submit a reviewable PR. Include risk, verification commands, deployment/rollback notes and documentation updates. Keep Compose validation, Python unit tests and shell checks green. Do not commit `.env` or secrets; preserve volumes and production data. Use SemVer for releases, documented in RELEASES.md. Update README technology/workflow badges when configurations change. Central guidance: https://github.com/drakeg/madmallard-repository-standards.
